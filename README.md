# 🌦 AeroNova Weather Map

A premium weather dashboard built with Streamlit.

## Features

- 🌍 Interactive Weather Map
- 🌤 Live Weather
- 🌡 Temperature
- 💧 Humidity
- 💨 Wind Speed
- 🌬 Pressure
- ☀ UV Index
- 🌿 Air Quality
- 📅 7-Day Forecast
- 🌅 Sunrise & Sunset
- 📱 Mobile Responsive

## Tech Stack

- Python
- Streamlit
- WeatherAPI
- Folium
- Pandas

## Installation

```bash
pip install -r requirements.txt
```

Create a `.env` file:

```env
WEATHER_API_KEY=YOUR_API_KEY
```

Run:

```bash
streamlit run app.py
```
